## Project Overview

### Writer AI — AI-Powered Writing and Coding Workspace

Writer AI is a modern Windows desktop application designed for developers, programmers, and users who want a convenient workspace for writing, coding, and AI-assisted productivity.

It combines a code editor, AI assistance, Markdown tools, PDF functionality, and an integrated terminal in one application.

**Key Features**

**1. Coding Workspace**
- Write code in multiple programming languages.
- Run code directly from the application.
- Convert code from one programming language to another using AI.
- Use an integrated terminal for command-line operations.
- Work in a dedicated coding environment.

**2. AI Integration**
- AI-powered writing assistance.
- AI coding assistance.
- Code conversion between programming languages.
- Groq AI integration.
- Google Gemini AI integration.
- Configure your preferred AI provider using its API key.

**3. Markdown Editor**
- Write and edit Markdown documents.
- Preview Markdown content.
- Live Markdown preview.
- Manage formatted documents in one workspace.

**4. PDF Support**
- Import PDF documents.
- Export documents as PDF.
- Work with document content alongside writing tools.

**5. Customization and Appearance**
- Modern, developer-friendly interface.
- Multiple appearance and theme options.
- Customizable font settings.
- Clean and comfortable coding environment.
- Workspace appearance designed around developer preferences.

**Why Writer AI?**

- AI assistance with supported free API tiers.
- Multiple AI provider options.
- Coding and writing tools in one application.
- Smooth and convenient development workflow.
- Customizable developer-focused interface.

**AI Providers:** Groq and Google Gemini.

**Platform:** Windows Desktop

## Download and Installation

### Installing Android Apps

1. Choose an Android application from the table.
2. Open its APK download link.
3. Download the APK from the provided release or asset.
4. Verify the file source and review the app permissions.
5. Install it on a compatible Android device.

Android may ask you to approve installation from an external source. Only install APK files you trust.

### Installing Windows Applications

1. Choose the Windows desktop application.
2. Open its official release or download page.
3. Download the available installer or package.
4. Follow the installation instructions.
5. Launch the application from your Windows desktop.

### Using Web Applications

1. Open the live demo link.
2. Use a compatible browser.
3. Follow the instructions provided by the application.

Web applications do not require APK installation.

## Download and Installation

### Installing Android Apps

1. Choose an Android application from the table.
2. Open its APK download link.
3. Download the APK from the provided release or asset.
4. Verify the file source and review the app permissions.
5. Install it on a compatible Android device.

Android may ask you to approve installation from an external source. Only install APK files you trust.

### Using Web Applications

1. Open the live demo link.
2. Use a compatible browser.
3. Follow the instructions provided by the application.

Web applications do not require APK installation.

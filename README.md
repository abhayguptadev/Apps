## How to Download and Use

### Android Applications

1. Choose an Android application from the list.
2. Open its official APK download link.
3. Download the APK from the verified release or asset.
4. Review the source and permissions before installing.
5. Install the app on a compatible Android device.

Android may require additional confirmation when installing apps outside Google Play. Only install APKs from sources you trust.

### Web Applications

1. Open the live demo link.
2. Use a supported web browser.
3. Follow the instructions provided by the application.

Web apps do not require an APK installation.
